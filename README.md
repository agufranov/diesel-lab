# Diesel Lab

Процедурный синтез звука дизеля в браузере: от легковушки до малооборотного Wärtsilä.
Записанные сэмплы не используются, весь звук считается из модели цикла двигателя.

## Запуск

```bash
python -m http.server 8765
```

Открыть http://localhost:8765. Ворклет собирается из Blob, поэтому `index.html` должен открываться и напрямую, через file:// (в обычном Chrome это пока не проверено).

Офлайн-тест ядра (уровни, обороты, проверка на NaN) и WAV-демки:

```bash
node tools/render-test.js --wav renders
```

## Сравнение версий

Переключатель «Модель звука» (или клавиша **V**) меняет модель на ходу, мотор продолжает работать:
- **v1** — первая версия: импульсы выпуска и шумовые всплески стука ([engine-v1.js](engine-v1.js), заморожена);
- **v2** — давление в цилиндре по Вибе, разброс цилиндров, крутильная неравномерность ([engine.js](engine.js)).

WAV обеих версий с одинаковой громкостью: `renders/v1/*.wav` и `renders/v2/*.wav`
(`node tools/render-test.js --wav renders/v2` и `node tools/render-test.js --v1 --wav renders/v1`).

## Экспорт для Derail Valley (ZSounds)

Панель «Экспорт для игр» собирает zip для мода [ZSounds](https://github.com/mspielberg/dv-zsounds):

```
Sounds/EngineLoop/<имя>.wav               петля на опорных оборотах
Sounds/EngineLoadLoop/<имя>_load.wav      петля под нагрузкой (игра подмешивает по газу)
Sounds/EngineStartup/<имя>_start.wav      пуск
Sounds/EngineShutdown/<имя>_stop.wav      останов
Sounds/Configs/<Тип>/config_<файл>.json   minPitch / maxPitch
```

Архив распаковывается в `Derail Valley/Mods/ZSounds/`, дальше в игре: Alt → ZS → Update Soundlist → выбрать звук для локомотива.
Петля — целое число рабочих циклов со сшитым кроссфейдом стыком. `minPitch = ХХ / опорные`, `maxPitch = максимум / опорные`.
Кнопка «Прослушать петлю» играет её так, как сыграет игра: один файл, сдвинутый по высоте.

Проверка без браузера: `node tools/export-test.js` (стык петель, валидность zip, архивы в `renders/zsounds`).

Не проверено в игре: как именно Derail Valley переводит обороты в `minPitch`/`maxPitch`. Если тон «не попадает»,
сравните с штатными значениями локомотива в редакторе конфигов ZSounds.

## Мод для Derail Valley (синтез в реальном времени)

[mod/](mod/README.md) — мод для Unity Mod Manager: то же ядро, перенесённое на C#, звучит прямо в игре по оборотам,
подаче и стартеру из симуляции локомотива и заменяет штатные петли двигателя.
Сборка: `powershell -ExecutionPolicy Bypass -File mod/build.ps1`. В игре пока не проверялся — чек-лист в [mod/README.md](mod/README.md).

## Как устроено

- `engine.js` — DSP-ядро `DieselCore` и AudioWorklet-процессор. Одна функция, которая работает и в ворклете, и в Node.
- `presets.js` — 9 двигателей: 1.9 TDI, МТЗ-80, КамАЗ-740, тягач R6, ДГУ V12, EMD 16-645, Wärtsilä 9L32 / 12V46 / RT-flex96C.
- `app.js` — UI, граф Web Audio (3 канала → панорама, фильтр позиции слушателя, свёртка помещения, компрессор).

Всё растёт из давления в цилиндре. Для каждого цилиндра в каждом цикле считается p(θ): компрессия по политропе плюс сгорание по двойной Вибе. Быстрая премикс-фаза задана во времени (доли мс, у крупных моторов дольше), диффузионная — в градусах. Подача, угол впрыска, задержка воспламенения и доля премикса защёлкиваются на каждый цикл со статическим разбросом по цилиндрам и случайным от цикла к циклу.

| Источник | Модель | От чего зависит |
|---|---|---|
| Выпуск | сила продувки ~√p в момент открытия клапана, разная длина и громкость патрубков, излучение ~dQ/dt, турбулентный шум, труба, глушитель | давление, разброс цилиндров, турбина |
| Блок | Σp → кривая структурного ослабления (ФВЧ 4-го порядка, Austen–Priede) → прямое излучение + 28 мод корпуса; низ — Σp через ФНЧ | резкость премикса, размер мотора |
| Газ в камере | после премикса звенят моды камеры `f = j'·c/(π·D)` | диаметр цилиндра, прогрев |
| Вращение | мгновенная скорость из момента цилиндров: «спотыкание» на прокрутке, неровный ХХ; регулятор «плавает» | число цилиндров, обороты |
| Механика | форсунки до ВМТ, посадка клапанов, удар давления сгорания | обороты, размер двигателя |
| Турбина | свист лопаток + шум воздуха, инерция (турбояма), ограничитель дымности | энергия выхлопа |
| Стартер | электро (вой мотора, модулированный компрессией) или пневмо (шипение) | неравномерность прокрутки |

Динамика: регулятор («педаль» у авто, всережимный у судовых и станционных), момент минус потери и нагрузка (винтовая характеристика), инерция, прогрев (холодный пуск: выше ХХ, больше стука, пропуски вспышек).

## Что дальше (идеи)

1. **Газодинамика выпуска**: 1D-волновод (как в Engine Simulator от AngeTheGreat) вместо гребёнки. Отдельные коллекторы для банков V-образных, реальный порядок работы, отражения от турбины.
2. **Давление в цилиндре по Вибе**: считать p(φ) из тепловыделения и брать стук из dp/dφ. Тогда задержка воспламенения, Common Rail, пилотный впрыск и EGR начнут влиять на звук сами.
3. **Структурный шум**: модальная модель блока, передача на раму и корпус, вибрация в машинном отделении.
4. **Позиция слушателя**: HRTF и реальные IR (машинное отделение, кабина, улица), расстояние с поглощением воздуха.
5. **Гибрид с сэмплами**: гранулярный слой поверх синтеза для механики, которую трудно смоделировать (шестерни, ТНВД).
6. **Калибровка по записям**: сравнивать спектрограммы с реальными роликами и подгонять параметры автоматически.
7. **Порт в нативный код** (Rust/C++ → WASM, плагин для FMOD/Wwise/Unity), чтобы использовать в играх и симуляторах.
