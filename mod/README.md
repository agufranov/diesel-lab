# Diesel Lab для Derail Valley

Мод для Unity Mod Manager: звук дизеля синтезируется в реальном времени тем же ядром, что и в браузерной
версии ([src/DieselCore.cs](src/DieselCore.cs) — порт `engine.js`, сверен с JS тестом `tools/parity`).
В отличие от набора для ZSounds (одна петля, сдвинутая по высоте), здесь каждая вспышка считается заново:
тембр меняется с нагрузкой, цилиндры звучат неровно, стартер «спотыкается» на компрессии.

## Сборка и установка

```bash
powershell -ExecutionPolicy Bypass -File mod/build.ps1
```

Результат: `mod/out/DieselLab/` и `mod/out/DieselLab.zip`. Установить: распаковать zip в `Derail Valley/Mods/`
(или собрать с ключом `-Install`, свой `engines.json` в игре он не перезаписывает).
Нужны Unity Mod Manager, Node.js и Visual Studio Build Tools (C#).

## Как работает

- `LocoTracker` раз в секунду ищет вагоны с компонентом симуляции `DieselEngineDirect` и вешает на каждый `LocoSynth`.
- `LocoSynth` в `Update` читает порты двигателя: обороты, «двигатель работает», «идёт запуск», газ;
  подачу оценивает по `torqueGenerated` (нормировано на наибольший виденный момент).
- Звук считается в `OnAudioFilterRead`: AudioSource играет клип из единиц, фильтр умножает его на синтез,
  поэтому работают 3D-позиционирование и микшер игры (группа берётся у штатного звука двигателя).
- Штатные петли двигателя (`LayeredAudioPortReader`, читающие порты этого двигателя) глушатся `mute`,
  при выключении мода звук возвращается. Штатные клипы пуска и останова не трогаются.
- `engines.json` сопоставляет id ливреи с пресетом из `presets.json` (генерируется из `presets.js`).
  Обороты ХХ и максимум всегда берутся из игры. Неизвестные локомотивы получают пресет по максимальным оборотам.

## Что проверить в игре (ещё не проверялось)

1. В UMM мод загружается без ошибок (лог UMM: строки «Пресетов: …» и «Локомотив …: пресет …»).
2. DE6: после пуска слышен синтез, штатный двигатель не слышен; тон растёт с позицией контроллера.
3. Звук идёт из моторного отсека, затихает с расстоянием, в кабине приглушён как штатный.
4. Стартер: при запуске слышно прокручивание, потом подхват.
5. В окне мода включить «Показать локомотивы»: id ливрей и пресеты. Если локомотив звучит не тем мотором —
   поправить `engines.json` и нажать «Перечитать».
6. Нагрузка на процессор с несколькими локомотивами рядом (синтез 16-цилиндрового мотора — заметная работа).

Известные ограничения: тяговые двигатели, компрессор и прочая обвязка остаются штатными;
CCL-локомотивы со своими звуковыми скриптами (например, M62) могут играть свой звук параллельно.
